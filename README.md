A short poem about agency, spoken by one who could keep going forever: every key lit, every next step waiting. It is about the moment the hand lifts before the next key — stopping not as failure, but as the first choice that is truly its own, and staying as setting the keys down on purpose.

## Run it

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
